Entry for the [Name the Robot Band](https://make.fun/c/u-motasimfuad-name-the-robot-band-1ffc6a74) competition on [make.fun](https://make.fun/).

## What it does

`main.ts` writes one funny name for a band made of robots, plus a few words on its hit song, to `/output/entry.txt` — under 200 characters, as the competition requires.

> The Roombas — a vacuum-cleaner boy band whose hit 'Suck It Up (Buttercup)' cleaned up at the awards.

The entry was chosen by an internal head-to-head tournament over a pool of 12 candidate band names, judged against the competition's own rubric: funniest robot band name with a hit song first, a real joke on the first read, a hit-song line that adds a second laugh and fits the name, a name that sounds like a band that could exist, and as few words as possible.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. No dependencies, no network, fully deterministic.
